Parallax

Parallax é um efeito visual onde o fundo se move a uma velocidade diferente do primeiro plano, criando uma sensação de profundidade.

Para implementar o efeito parallax, você pode usar CSS e JavaScript.

O CSS permite definir a imagem de fundo e aplicar o efeito de movimento, enquanto o JavaScript pode ser usado para ajustar a posição do fundo com base na rolagem da página.

O efeito é frequentemente utilizado em sites modernos para criar uma experiência de usuário mais envolvente.

Para ver o efeito, role a página para baixo.
